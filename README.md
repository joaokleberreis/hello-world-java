# hello-world-java

Meu primeiro projeto em Java, criado para praticar os conceitos básicos da linguagem.

O programa exibe a mensagem "Olá, Mundo!" no console usando `System.out.println`.


## Sobre o projeto

- **Linguagem:** Java
- **IDE:** IntelliJ
- **Objetivo:** Praticar saída de dados com `System.out`.
